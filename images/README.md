# Product photos

Drop your real product photos in this folder (square photos look best, e.g. 800×800).

Then open `script.js` and set the `image` field of the matching product, for example:

```js
{ name: "Pastel Scrunchie Set (3 pcs)", price: 249, category: "hair", sub: "Scrunchies", image: "images/scrunchie-set.jpg", featured: true },
```

For the About section, add a photo named `about.jpg` here.
