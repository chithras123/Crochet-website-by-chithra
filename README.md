# Tamaraa — Handmade Crochet Website

A simple, mobile-friendly shop website built with plain HTML, CSS and JavaScript (no frameworks).

## Files
- `index.html` — page layout (Home, Shop, About, Contact)
- `style.css` — soft pastel styling
- `script.js` — shop settings and the product list
- `images/` — put your product photos here

## Editing
Open `script.js`:
- **Shop name, WhatsApp number, Instagram link** — at the very top.
- **Products** — the `PRODUCTS` list. Each product has a `name`, `price` (₹), `category`, optional `sub` category, `image` and `featured` (shows on the Home page).

## Deploying on Vercel
Import this repository in Vercel and deploy — no build settings needed (Framework preset: **Other**).
